# Hi, I'm KXH

I build reliable AI agent applications and practical engineering tools with
Python, TypeScript, and C#. My current focus is agent orchestration,
tool integration, human approval workflows, observability, and reproducible
delivery.

## Featured Agent Projects

### [OperCerta](https://github.com/KXHXK/opercerta)

An auditable operations agent for inventory exceptions, equipment alerts, and
human-approved work orders. Built with FastAPI, LangGraph, FastMCP,
PostgreSQL, React, Redis, and OpenTelemetry.

- [Project showcase](https://opercerta-kxh.netlify.app)
- Includes deterministic evaluation, idempotent tool execution, approval
  checkpoints, restart recovery, and CI-backed evidence.

### [HelloAgents Trip Planner](https://github.com/KXHXK/helloagents-trip-planner)

An educational multi-agent travel planner with specialized weather,
attraction, hotel, and itinerary agents. Built with FastAPI, Vue 3,
TypeScript, and external travel APIs.

- [Live frontend](https://helloagents-trip-planner-kxh.vercel.app)
- Supports mock services for local development without consuming API quotas.
